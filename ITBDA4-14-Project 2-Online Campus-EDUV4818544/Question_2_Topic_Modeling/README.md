

\# Question 2 - LDA Topic Modelling



\## Purpose

Analyse 10 news documents using R and RStudio.



\## Question 2.1

Load news files into a data frame and preprocess the text.



\## Question 2.2

Apply Latent Dirichlet Allocation (LDA).

Identify 3 topics and the top 8 words per topic.

Report topic-word and document-topic probabilities.



\## Question 2.3

Create two visualisations:

1\. Horizontal bar charts.

2\. Topic-word probability heatmap.



\## R Scripts

01\_load\_preprocess.R - Load and clean news documents.

02\_lda\_topics.R - Apply LDA topic modelling.

03\_visualize\_topics.R - Generate the visualisations.

04\_run\_question2.R - Run the complete analysis.



\## Required Packages

tm

topicmodels

ggplot2



\## Execution

Open the main RStudio project.



Run:

source("Question\_2\_Topic\_Modeling/R/04\_run\_question2.R")



\## Outputs

Cleaned news data.

Top topic keywords.

Word probability distributions.

Document-topic probabilities.

LDA model.

Two PNG visualisations.
